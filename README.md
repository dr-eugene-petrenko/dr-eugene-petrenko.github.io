# Сайт Євгена Петренка

Публікується на GitHub Pages з гілки `main`, папка `docs/`:
https://dr-eugene-petrenko.github.io

## Як змінити сайт

- Текст і оформлення кожної сторінки лежать у `src/pages/<сторінка>.html`
  (а її стилі з `<head>`, якщо є, у `src/pages/<сторінка>.head.html`).
- Фото — у `src/images/`, на сторінках вони доступні як `/images/<файл>`.
- Шапка, меню та віджет асистента Shukai задаються один раз у `build.py`.

Після змін зберіть сайт і запуште:

```bash
python3 build.py
git add -A && git commit -m "Оновлення сайту" && git push
```

GitHub оновлює сайт за хвилину-дві.

Сторінки перенесено з Google Sites (dr-petrenko.com.ua) 2026-11-07, адреси сторінок
збережено (`/досвід/`, `/наука/`…). Попередня чернетка на Quarto лежить у гілці `quarto-draft`.
